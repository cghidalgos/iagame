## 🚀 **Cómo Probar la Aplicación**

### **Opción 1: Local**
```bash
python app.py
# Abrir: http://localhost:5004
```

### **Opción 2: Docker**
```bash
docker-compose up --build
# Abrir: http://localhost:5013
```

### **Flujo de Usuario:**
1. **Inicio** → Click en "Comenzar"
2. **Trivia** → Responder 10 preguntas sobre historia de IA
3. **Laberinto** → Guiar al robot 🤖 hasta la salida 🚪
4. **Alan Turing Challenge** → Capturar imágenes de Alan Turing en 30 segundos
5. **Formulario** → Evaluar habilidades en IA (1-10)
6. **Resultados** → Ver puntaje final y perfil profesional asignado
7. **Ranking** → Comparar con otros participantes
